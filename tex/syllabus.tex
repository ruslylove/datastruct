\section*{Course Description}
This course introduces students to the fundamental data structures and algorithms
used in computer programming. Topics include linear structures such as
\emph{lists}, \emph{stacks}, and \emph{queues}, and non-linear structures such as
\emph{trees} and \emph{graphs}. The course also covers core algorithmic techniques
for \emph{sorting}, \emph{searching}, and \emph{recursion}, and emphasises the
selection of appropriate data structures and algorithms for problem solving.

\section*{Course Learning Outcomes (CLOs)}
Upon successful completion of this course, students will be able to:
\begin{enumerate}
  \item Demonstrate a good understanding of linear data structures, including
        arrays, linked lists, stacks, and queues.
  \item Implement abstract data types effectively.
  \item Understand non-linear data structures, including trees and graphs.
  \item Select and use appropriate data structures to solve specific problems.
  \item Understand and implement sorting, searching, and hashing algorithms.
  \item Choose and apply appropriate algorithms to solve specific problems.
\end{enumerate}
